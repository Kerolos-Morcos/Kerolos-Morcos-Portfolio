# Kerolos Morcos Portfolio

Vue 3 + Vite portfolio for Kerolos Morcos, a Full-Stack Developer using Vue.js and Node.js.

## Local development

```sh
npm install
npm run dev
```

## Production build

```sh
npm run build
npm run preview
```

The site defaults to Arabic RTL, supports English LTR, persists language/theme/font preferences, and includes the supplied CV at `/Kerolos-Morcos-Full-Stack-Developer-CV.pdf`.
